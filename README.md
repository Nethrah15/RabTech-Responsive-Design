# RABTECH - Task 4 Responsive Design Tokens & Mobile-First CSS

## What I Built
Responsive Expense Tracker Dashboard with Design Tokens

## Features
- Design Tokens in :root - colors, typography, spacing, border radii
- Mobile-First Grid - 1 col (mobile) -> 2 col (768px) -> 3 col (1024px) -> 1440px
- Glassmorphism - backdrop-filter blur, soft shadows, hover transitions
- Dark / Light Theme - CSS variables toggle
- Zero horizontal scroll on mobile

## Breakpoints Tested
320px, 768px, 1024px, 1440px

## Tech
HTML, CSS Custom Properties, CSS Grid, Flexbox
